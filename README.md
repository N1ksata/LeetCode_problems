# LeetCode Problems

A clean, growing collection of LeetCode solutions organized for quick revision and steady interview preparation.

## Goals

- Keep solutions easy to read and revisit
- Cover problems across difficulty levels and patterns
- Build a reliable reference for interview practice

## Repository Status

This repository is currently at an early stage and ready for expansion.

## Suggested Organization

As more solutions are added, prefer grouping by topic and difficulty, for example:

- `arrays/`
- `strings/`
- `linked-list/`
- `trees/`
- `dynamic-programming/`

Inside each folder, use clear filenames such as:

- `two-sum.py`
- `valid-parentheses.cpp`
- `binary-tree-level-order-traversal.js`

## How to Use

1. Pick a topic folder
2. Open a solution file
3. Review the approach and complexity notes
4. Re-solve from scratch for retention

## Contribution Notes

If you add a new problem solution, keep it consistent:

- Use descriptive file names
- Keep one primary solution per file
- Include time and space complexity in comments when useful

## Roadmap

- Add more solved problems
- Add problem links near each solution
- Add optional test snippets where relevant
